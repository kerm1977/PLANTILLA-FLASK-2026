Todo lo que necesitas para ejecutar el servidor y generar tu proyecto con Cookiecutter.

Ejecutar el servidor

Desde la carpeta raíz de esta plantilla:

{% raw %}.\venv\Scripts\python.exe "{{cookiecutter.project_slug}}\app.py"{% endraw %}

Cuando Cookiecutter haya generado tu proyecto:

.\venv\Scripts\python.exe app.py

Abre la app en http://127.0.0.1:5000.

Crear un proyecto con Cookiecutter

  1. Instala Cookiecutter: 
    python -m pip install cookiecutter
  2. Genera el proyecto desde esta plantilla: 
    cookiecutter .

    También puedes usar el repositorio remoto:

    cookiecutter https://github.com/kerm1977/PLANTILLA-FLASK-2026.git
  3. Responde las preguntas en la terminal.
  4. Entra a la carpeta generada e instala las dependencias: 
    python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
  5. Ejecuta el servidor: 
    .\venv\Scripts\python.exe app.py
